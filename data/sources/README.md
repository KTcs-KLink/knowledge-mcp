# 원본 문서

이 폴더에는 Git으로 공유할 권리가 확인된 원본만 둡니다. 공개 웹페이지라는 이유만으로 재배포가 허용되는 것은 아니므로 게시처의 이용 조건을 확인하세요.

- 파일명은 manifest의 `source_id`와 맞춥니다. 예: `SRC-0001.pdf`.
- 원본 및 추출 텍스트의 공유가 허용되지 않거나 조건이 불분명하면 원본과 청크를 올리지 말고 `data/manifests/sources.csv`에 출처 URL과 확인 상태만 기록합니다.
- 개인 정보, 비공개 문서, KTcs 내부 자료, 비밀키는 올리지 않습니다.
- 파일이 크거나 이용 조건을 판단하기 어렵다면 업로드 전에 팀에서 확인합니다.
