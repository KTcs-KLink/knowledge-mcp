# 출처 목록

`sources.csv`에 원본 문서 한 건당 한 행을 기록합니다. `source_id`는 `SRC-0001` 형식으로 만들고 중복·재사용하지 않습니다.

- `source_url`: 자료를 확인할 수 있는 공식 출처 URL
- `published_at`, `retrieved_at`: 게시일과 수집일. 확인할 수 없으면 비워 둡니다.
- `license_or_terms`: 이용 약관, 라이선스 이름 또는 확인한 안내 링크
- `redistribution_allowed`: `yes`, `no`, `unknown` 중 하나. `yes`가 아니면 원본과 청크 텍스트를 Git에 올리지 않고 출처 정보만 기록합니다.
- `sha256`: 원본 파일을 저장소에 넣는 경우 파일 무결성 확인용 해시
- `notes`: 자료의 범위, 이용 조건 확인 내용 등 필요한 메모

출처나 재사용 조건이 확인되지 않은 자료는 검색·답변 평가 데이터로 사용하기 전에 확인합니다.
