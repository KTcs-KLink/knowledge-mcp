# Architecture Decision Records

여러 기능이나 저장소에 영향을 주는 중요한 기술·구조 결정만 이 폴더에 기록합니다. 결정 하나당 `0001-short-title.md`처럼 번호를 붙인 파일 하나를 만듭니다.

템플릿은 조직 저장소의 [ADR 템플릿](https://github.com/KTcs-KLink/.github/blob/main/adr-template.md)을 복사해 사용합니다. 상태는 `제안`, `승인`, `기각`, `대체됨` 중 하나로 표시합니다. 작은 구현 선택은 ADR 대신 PR 설명에 남깁니다.
