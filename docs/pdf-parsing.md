# PDF → Markdown 파싱

Python 3.11 이상에서 저장소 폴더의 터미널로 실행한다.

```powershell
python -m pip install -r requirements-parsing.txt
python src/ingestion/pdf_parser.py
```

기본 입력은 data/raw 안의 PDF다. 하위 폴더는 탐색하지 않는다.
HWP/HWPX 직접 파싱은 아직 지원하지 않으며 해당 파일은 건너뛴다.

파일 하나 또는 출력 폴더를 지정할 수도 있다.

```powershell
python src/ingestion/pdf_parser.py "data/raw/인사관리규정.pdf" --out "data/parsed"
```

## 출력

- 문서별 `data/parsed/문서명_SHA앞8자리/parsing.md`
- 실행 요약 `data/parsed/run_summary.md`: 성공·실패·건너뛴 파일과 사유
- JSON이나 별도 프리뷰는 생성하지 않는다. 기존 출력 폴더에 남은 과거 JSON은 자동 삭제하지 않는다.

```markdown
# 이사회규정

> 원본: 이사회규정.pdf

## 제2조(구성)

① 첫 항의 내용이다.

② 다음 표를 따른다.

| 구분 | 인원 |
| --- | --- |
| 상임이사 | 7인 이내 |

[본조신설 1999.4.2]
```

장·절·조 제목은 Markdown 제목 수준으로 구분한다. 같은 조의 항·호·이력을 해당 조 아래에 모으고, 표는 본문에 있던 위치에 삽입한다. 부칙과 별표도 별도 제목으로 구분한다.
Markdown에는 페이지 번호·전체 쪽수·bbox·셀 좌표·블록 ID를 출력하지 않는다. 페이지 정보는 실행 중 내부 데이터에만 유지되며, 현재 MD 파일만으로는 조별 원문 페이지를 복원할 수 없다. 이후 출처에 페이지를 제공하려면 파싱 단계의 내부 데이터를 별도로 전달해야 한다.
표의 `|`는 이스케이프하고 셀 내부 줄바꿈은 `<br>`로 표현한다. 첫 행은 Markdown 표의 헤더 위치에 배치하므로, 실제 첫 행이 제목인지 여부는 원문과 대조한다. 병합 셀은 일반 Markdown 표로 정확하게 표현할 수 없다.

## 코드 구성

- `src/ingestion/pdf_parser.py`: 실행 파일. 문단 복원, 삭제 정제, 조 단위 묶기, Markdown 저장.
- `src/ingestion/_pdf_layout.py`: 단 배치·읽기 순서·표 추출·연결. 파서가 내부에서 불러온다.
- `tests/test_*.py`: 회귀 테스트. 파싱 실행에는 별도 실행할 필요가 없다.

Markdown으로 출력해도 PDF 배치와 표를 읽는 처리는 필요하므로 해당 코드는 유지한다. 프로그램 내부에서는 본문·표를 딕셔너리로 처리하며 최종 파일만 Markdown으로 저장한다.

## 처리 기준과 한계

- pdfplumber로 텍스트와 선 기반 표를 추출한다. 표 안의 글자는 일반 본문에서 제외한다.
- 중앙 여백과 좌우 배치로 1단·2단을 추정한다. 전체 너비 제목·표를 경계로 왼쪽 단, 오른쪽 단 순서를 적용한다.
- 반복 머리말·꼬리말을 제거한다. `--keep-margins`로 비활성화할 수 있다.
- 삭제된 조·항·호·별표의 자리표시와 삭제 주석은 제외한다. 첫 항만 삭제된 경우 조 제목은 남긴다. 실제 업무 내용에서 사용하는 ‘삭제’는 유지한다.
- 표 연결은 읽기 순서상 인접한 표의 위치·폭·열 구조와 반복 첫 행 또는 연속 번호를 비교한다. 불확실하면 별도 표로 유지하고 확인 안내를 남긴다. `--no-merge-tables`로 연결을 끌 수 있다.
- 문단은 줄 간격·들여쓰기·글자 크기·문장 경계로 복원한다. 문장 끝 ‘다.’를 목록과 구분하고 여러 줄에 걸친 개정 날짜를 연결한다. 한국어 단어 중간의 임의 분할은 추가 확인이 필요하다.
- 다음 조·장·절·부칙·별표를 만나면 이전 조를 끝낸다. 계층 전체 구조화, 부모·자식 청킹, 임베딩은 후속 단계다.
- OCR·HWP 직접 파싱은 포함하지 않는다. 전체에서 텍스트를 추출하지 못하면 실패하며, 일부 페이지가 비어 있으면 확인 안내를 남긴다.
- 선 없는 표, 복잡한 병합 셀, 셀 중간 분할, 불규칙한 다단은 자동 복원이 보장되지 않는다.
- 결과에는 원문 내용이 포함되므로 자료 재배포 조건을 확인한 뒤 공유한다.

## 검증

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

원문과 parsing.md를 대조하여 조의 경계·항목·표의 행열과 위치를 확인한다. 합성 입력의 테스트가 모든 실제 PDF의 정확성을 보장하지는 않는다.
